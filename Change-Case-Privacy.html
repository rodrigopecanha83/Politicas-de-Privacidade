Privacy Policy for the Extension:
"Change Case Chrome Extension"

Last updated: October 13, 2026

Your privacy is important to us. This Privacy Policy explains how the Google Chrome extension "Change Case Chrome Extension" (hereinafter referred to as the "Extension") handles your information.

1. Data Collection and Use

The Extension does not collect, store, transmit, track, or share any personal, browsing, or clipboard data of the user.

The functionality of the Extension is performed entirely within your local browser. It is designed strictly for text formatting and case conversions (Sentence case, Title Case, UPPERCASE, lowercase, CONSTANT_CASE, PascalCase, camelCase, snake_case, dot.case, param-case, and accent removal).

No text from your clipboard or web page selections is ever sent to external servers, cloud databases, analytics services, or third parties.

2. Required Permissions

To function correctly, the Extension requests the following permissions in Google Chrome:

  • clipboardRead & clipboardWrite: Essential for reading text currently copied to your clipboard and writing the formatted text back to your operating system's clipboard.
  • contextMenus: Allows displaying conversion options in the right-click menu when you select text on any web page.
  • scripting & activeTab: Used strictly upon explicit user interaction (keyboard shortcut or context menu click) to read the selected text on the active tab and insert the converted text directly into editable form fields, or display a brief visual confirmation toast. Operates exclusively on the active tab and never runs in the background without user action.

3. Remote Code

The Extension does not load, fetch, or execute any remote code (such as external scripts or WebAssembly). All code runs exclusively from the verified local extension package.

4. Changes to this Privacy Policy

We may update our Privacy Policy from time to time. Any changes will be posted on this page. You are advised to review this page periodically to stay informed.
